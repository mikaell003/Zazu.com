How to Use the Mind Mapper

  • Add Node: Click the "Add Node" button, then click on the canvas to place a new node
  • Add Child Node: Select a node and click "Add Child Node" to create a connected child node
  • Connect Nodes: Select two nodes and click "Connect Nodes" to create a relationship
  • Edit Node: Select a node and click "Edit Node" to modify its content and appearance
  • Move Nodes: Drag nodes to reposition them on the canvas
  • Save/Load: Save your mind map to local storage or load a previously saved one
