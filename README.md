# Zazu Smart Toolbox 🧰

Zazu Smart Toolbox is a free, web-based digital hub built for everyday productivity. It features a collection of lightweight utilities for managing documents, modifying PDFs, and utilizing practical tools across creative and business projects—all from a single interface.

🔗 **Live Link:** [zazusmarttoolbox.netlify.app](https://netlify.app)

---

## ✨ Features

*   **Document Utilities:** Convert, compress, and edit text files on the fly.
*   **PDF Management:** Merge, split, or modify PDF documents directly in your browser.
*   **Media & Design:** Quick image cropping, formatting, and creative assets tools.
*   **Security Tools:** Simple, client-side encryption and text hashing.
*   **Privacy First:** No login or registration required. All processing happens locally in your browser.

---

## 🚀 Getting Started

Because this project is built entirely with vanilla web technologies, you do not need to install any dependencies or run a build process.

### Prerequisites

You only need a modern web browser (like Chrome, Firefox, Edge, or Safari) installed on your machine.

### Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com
   ```

2. Navigate to the project directory:
   ```bash
   cd zazu-smart-toolbox
   ```

3. Launch the project:
   *   **Option A:** Simply double-click the `index.html` file to open it in your browser.
   *   **Option B (Recommended):** Open the folder in a code editor like VS Code and use an extension like **Live Server** to launch a local development server.
